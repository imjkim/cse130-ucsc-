There are only a few functions in my implementation. They include the three methods, GET, HEAD, and PUT, and I also made a function to take care of all the bad requests before calling any of the above methods. 

My initial approach to my design was to have a response and request structs, but I replaced them by just passing in the essential variables for the requests to the three methods, and passing the response to the client in the method functions. There were a couple reasons for this revision. The primary one being that I thought it was wasteful to declare a struct with all the possible variables it might need, only to run a program that does not utilize them. By allocating space for a variable only when you need it, and freeing in right after using it, seemed to be more resourceful. An example is only needing to use a GET or HEAD method. Response struct would need a message and header, but if I were to only use those methods, those variables of a struct would never be touched. 
   Parsing the strings seemed to be a crucial aspect of this assignment, and I primarily used sscanf in order to do so. Since I have separate functions and pass in the necessary variables as parameters, I decided to get the first word of the input(client side) line, and then use sscanf again, in order to fetch the necessary variables for the specific methods.
