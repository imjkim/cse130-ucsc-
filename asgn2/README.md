   This assignment required the develpers to design an api with a given header file. Therefore, there are not much of a room for unique designs. I have not created any additional functions aside those of which have been declared in the header file. 
   Aside from the functions, I defined the given typedef struct in the source file, and since it has been introduced with the keyword typedef, all I did is make the essential variables, such as tail, head, count, and head. Another variable I declared is the pointer to the items, which we were not given a specific variable type for, and created a new struct to hold whatever type it will be used for. Initially, I tried to do it with int pointer, and then a pointer of unsigned char, but they resulted in a lot of problems in the process, so I made a new struct for the pointer.
   This assignment required a decent understanding of using synchronization and pthread library. I had to make one mutex for the functions to be able to deal with critical section with synchronization. This is necessary, because there are multiple threads or processes accessing the functions, and their corresponding data, and it is important for the functions to fully execute without being interrupted. 
  Another factor I made, which is necessary, is the conditions. I made two, one for when the queue is full to its size, and one for when it is empty. This is essential, because when a thread tries to dequeue when it is empty, it will cause an error. However, by making it wait under the condition that it is empty, and then executing once it is not empty, we are able to bypass this error.
